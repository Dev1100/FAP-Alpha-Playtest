# FAP / Кинерма — публичный playtest

**Скачать:** [релиз r15](https://github.com/Dev1100/FAP-Alpha-Playtest/releases/tag/alpha-2026-09-26-r15). Скачайте все семь файлов релиза в одну папку, запустите `Install_FAP_Alpha_r15.cmd`, затем `FAP_Alpha_r15\Windows\FAP_Alpha_DX11.cmd`.

Если игра закрывается с ошибкой DX11, запустите `FAP_Alpha_DX11.cmd -windowed -ResX=1280 -ResY=720`.

Это технический кандидат для проверки. Формальный Alpha Gate ещё открыт. Инструкция и вопросы для теста находятся в описании релиза и `README_FAP_Alpha_r15.txt`.
